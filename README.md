# Web-site

Site vitrine sobre : logo qui tourne en haut à gauche et la collection (2 articles).

## Contenu

- `index.html` — la page
- `style.css` — la mise en page
- `script.js` — bascule Avant / Arrière (survol sur ordinateur, tap ou boutons sur mobile)
- `images/` — logo détouré (`logo.png`, `favicon.png`) et photos recadrées au format 4:5

## Voir le site

Ouvrir `index.html` dans un navigateur — aucune installation nécessaire.

## Ajouter un article

Copier un bloc `<article class="product">…</article>` dans `index.html`, puis changer les deux
photos (avant / arrière, format 4:5 conseillé, ex. 1000 × 1250 px) et le nom.
